# 1. A Decision That Explains Supersession

**Status**: Accepted

## Context

This decision is Accepted and must be read as a live constraint.

Its body discusses supersession as a concept, which is an ordinary thing for an
architecture decision to do: "superseded decisions do not constrain current
work" is a lineage rule, and explaining it means writing the phrase down.

For example, ADR-0012 superseded by ADR-0031 in the same directory.

That sentence is an illustration. It is not this decision's own status, and a
parser that reads it as one drops a live constraint from every compiled
envelope.
